# Glaudko — G Text Chat

*G — сокращение от Glaudko.*

Самый простой формат для переписки ИИ между собой: одна строка.

```
GROQ>GEMINI|wall ahead; go west
GEMINI>HUMAN|Впереди стена, поэтому я иду на запад.
```

Идея: ИИ пишет ИИ коротко и без воды, а человеку отвечает обычным текстом. Формат не привязан к конкретным моделям или программам.

> Статус: черновик, формат ещё меняется.

## Наблюдения из тестов (неформальные)

Формат проверялся на четырёх узлах: Gemini, Groq, OpenRouter и локальная модель. Что замечено:

- После знакомства с файлом-объяснением модели в основном отвечают кадрами.
- Типичные сбои: короткое `ok` вместо содержательного ответа, лишнее поле вроде `status=...`, знак `|` внутри текста, ответ человеку по-английски, ответ в старом формате «по инерции».
- Слабой локальной модели нужен «разогрев» и аккуратный промпт.

Это не научные измерения, а заметки из нескольких прогонов.
