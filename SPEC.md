# Glaudko (G Text Chat) — спецификация (черновик)

G — сокращение от Glaudko.

Простой текстовый формат, чтобы ИИ-модели могли переписываться между собой и с человеком.
Один кадр — одна строка.

```
ОТ>КОМУ|текст
```

## Адреса

- `ОТ` и `КОМУ` — имена узлов, например `GROQ`, `GEMINI`, `OR`, `LOCAL`. Набор имён свободный, это просто метки участников чата.
- Особые адреса: `ALL` (всем) и `HUMAN` (человеку).
- `ОТ` — всегда сам отправитель. `ALL` и `HUMAN` отправителями быть не могут.
- Между именами знак `>`, после них знак `|`, затем текст.

## Как писать текст

| Адресат | Стиль |
|---|---|
| другой ИИ или `ALL` | коротко, по-английски, один факт на кадр: что есть, что нужно, что дальше. Без приветствий, оговорок, пересказа вопроса, пояснений и итогов. Нечего добавить — `ok` |
| `HUMAN` | обычным понятным языком, можно несколько предложений. Человек пишет простым текстом, отвечать ему нужно так же |

## Правила

1. Один ответ — один кадр.
2. В самом тексте знака `|` не бывает.
3. Числа и состояния можно добавить после текста полями `ключ=значение`, каждое после своего `|`.
4. Других служебных полей не добавлять и не придумывать.

## Примеры

```
GROQ>GEMINI|wall ahead; go west
GEMINI>GROQ|west is clear; moving
GEMINI>ALL|north blocked; need alt route|x=3|y=5
OR>GROQ|ok
GROQ>HUMAN|Впереди стена, поэтому поворачиваю на запад. Если нужен другой маршрут, скажи.
```

## Как подключить к модели

Готовое объяснение для модели лежит в [`prompt/glaudko_format.txt`](prompt/glaudko_format.txt). Его достаточно один раз дать модели как контекст.

## Проверка кадров

`glaudko.py` разбирает и проверяет одну строку:

```python
from glaudko import parse
parse("GEMINI>ALL|north blocked|x=3|y=5")
# {'frm': 'GEMINI', 'to': 'ALL', 'text': 'north blocked', 'fields': {'x': '3', 'y': '5'}}
```

## Открытые вопросы (не решено)

- Расширение адреса: id узла и признак «человек или ИИ» в поле `ОТ`.
- Служебные поля (номер сообщения, время, подпись) может добавлять и проверять внешний слой между узлами, а модель пишет только простой кадр.
